## T1

- 목적: 지정 IP 직접 P2P만 쓴다. STUN/TURN·relay 잔재를 없앤다.
- 변경: `server/signaling`(turn.go 삭제, ICEServers·turn-refresh/turn-credentials·TURN 검사 제거), `ScreenShareSession`(ICE 서버 조립·RefreshLoop·HasTurn 제거, 끊김 복구는 `RestartTransport` = 다음 generation offer), `ScreenShareOptions.StunServers`(무시), Viewer `iceServers`·Relay 표시 제거, `deploy/coturn`·`scripts/prepare-turn.ps1` 삭제, compose·prepare-signaling·방화벽 TCP 25002/25003 제거, 문서.
- 검증: `go test ./...`, Host.Core 테스트, Viewer 테스트.
- 완료 기준: 코드에 TURN/STUN 서버 사용이 없다.

## T2

- 목적: 대상자 조작이 필요한 경로를 없앤다.
- 변경: Tray의 `ConsentWindow`·`AdminConsentWindow`·`ActionConsentWindow`·`LocalActionWindow`·"새 지원 코드 만들기" 삭제, `LocalApprovalGate`·`RunbookApproval` 삭제, 시그널링 consent 중계 삭제, ScreenShareSession의 `RequestLocalConsent`·`WithLocalApproval` 삭제. 수신 파일은 `DownloadFolder`(다운로드\RemoteAssist)에 자동 저장.
- 검증: 빌드, 테스트.
- 완료 기준: 승인 창·승인 타임아웃 코드가 없다.

## T3

- 목적: 항상 전 권한이므로 기능 단위 게이트를 고정값으로 바꾼다.
- 변경: `PermissionGate`(Grant(session, connection) → Capability.All, 세션 종료 차단만), `AdminAuthorization`(세대 발급만), `AdminContracts`(수명 검사 제거), `FeatureContract`(고정 목록), `ControlMessage`(local-approval 제거, monitor-state inputEpoch), Viewer 고정 PERMISSIONS/CHANNELS, `tests/fixtures/features.json`.
- 검증: 테스트 갱신(InputRegression, AdminRegression, FeatureRegression, 연결 테스트).

## T4

- 목적: 시그널링 시작을 막는 운영 전제를 선택 사항으로.
- 변경: `RA_MODE=development|lan|production`. operator secret·감사 디렉터리·Viewer 디렉터리·Origin 선택. 발급 속도 제한·이름 검증 제거(이름은 다듬기만), Viewer 교체(`replaced`/`busy`).
- 결정: 평문 LAN(TLS 끄기)은 도구 권한 분류기가 거부해 넣지 않았다. lan 모드도 TLS 필수이며 자체 서명 인증서 + Host 핀 고정으로 쓴다.
- 검증: `lan_test.go`, `configuration_test.go`, 교체 테스트.

## T5

- 목적: 개발 중 가장 큰 마찰인 보호 경로 검사를 끈다.
- 변경: `InstallationState.Development`(정식 versions 경로 밖이면 true) → `DemandProtected`·`CheckCandidate`·`ProtectedInstallation.ResolveExecutable` ACL 검사 생략, `StartupPreparation`의 dev-owner·manifest 검사 제거와 방화벽 검증 실패 경고 처리, `DevSupportLauncher` 소유 표식 검사 제거, `install-host-dev.ps1` 단순화.
- 남은 일: 정식 설치 검사는 배포 단계에서 다시 검토한다.

## T6

- 변경: `Host.Recovery` 프로젝트·`RecoveryScope`·`RecoveryLedger`·`WindowsRecoveryBackend`·`CrashSessionAudit`·`LocalStopMark`·`CaseTrace`·media-lease 감시 삭제. 키 해제는 `InputSession`(정지·일시 중단)과 AdminHelper(데스크톱 이탈)가 맡는다. 감사 실패는 지원을 막지 않는다.

## T7

- 목적: 일반·관리자 창을 한 경로로, 모니터·데스크톱 전환을 끊김 없이.
- 결정: 연결되면 항상 관리자 모드로 들어가 SYSTEM AdminHelper가 현재 입력 데스크톱을 캡처·입력한다. WebRTC·인코딩은 일반 Helper에 둔다. 관리자 헬퍼 실패 시 일반 모드로 계속.
- 변경: `AdminDesktopRuntime`(만료·lease·보안 데스크톱 30초 제한 제거, `admin-monitor` 재바인딩, 이전 좌표 입력은 버림, 데스크톱 이탈 시 키 해제), `ScreenShareSession.SwitchMonitor`(관리자 모드 포함), `FollowFormatChange`(같은 모니터 또는 주 모니터로 자동 재맞춤), 일반 모드 보안 데스크톱은 세션 유지.
- 남은 일: 두 PC·서로 다른 GPU에서 UAC 캡처·입력 실측(T14).

## T8

- 변경: `RunbookMessage` `bookId:"command"`·`args{script,admin}`·`ScriptHash`, `RunbookCatalog.Demand`, `RunbookExecution`(-EncodedCommand, stdout 8192·stderr 4096), Runbook Job 프로세스 64개·메모리 상향, 감사 BookId `command`, Viewer 원격 명령 패널.

## T12

- 지속 허가: `InitialSupportLaunch`를 소비형에서 지속형으로(콘솔 세션·사용자 SID·로그온 시각 결합). 서비스 재시작·업데이트 뒤 유지, 재부팅·로그오프·사용자 변경·즉시 종료에서 소멸. 런처는 성공한 허가를 지우지 않는다.
- 업데이트 gate: `session.gate`는 지원자가 연결된 동안만 잡는다. 대기 중에는 업데이트가 진행된다. 제거 시 허가 파일 정리.
- 인코더 검증(이 PC: RTX 4060, i7-12700KF, 합성 1080p 60프레임, `HostRun --encoder-check`, 2026-10-23 실측): h264_nvenc PASS 81.4fps, h264_mf PASS 104.3fps, libopenh264 PASS 62.7fps, h264_qsv 미지원(iGPU 없음), h264_amf 미지원(AMD 런타임 없음). 검사 중 h264_amf의 `profile=baseline` 거부를 발견해 `constrained_baseline`으로 고쳤다(AMD 실기 미확인).
- 남은 일: 정식 서명 인증서로 설치·업데이트·rollback 실기 수용, 다른 GPU(Intel QSV·AMD AMF) 장치 검증.
