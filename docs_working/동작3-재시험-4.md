# 동작 3(관리자/UAC) 재시험 계획

[수동-실연결-테스트-3](수동-실연결-테스트-3.md)의 동작 3만 다시 한다. 1차 시험(2026-10-23)에서 B(Intel UHD + GTX 1660 Ti)의 AdminHelper DXGI 복제가 `0x887A0004`로 실패했다. 그 뒤 `prepare-host.ps1`이 AdminHelper에 절전 GPU(`GpuPreference=1;`)를 지정하도록 고쳤다(3f5a197). 사용자 프로세스로 실측한 결과, 같은 지정에서 `DuplicateOutput`이 성공했다.

- 후보: `main` 최신 커밋(36d57bf 이후). `e2e-prepare.ps1 -Install -StartTunnel -PasswordEnv`로 준비한다. 새 스크립트 경로도 함께 확인한다.
- 목적: 관리자 모드가 켜지고, B의 UAC 보안 데스크톱이 A에 보이며, A의 클릭이 반영되는지 확인한다.
- 확인 증거:
  - Viewer 상태 문구가 "관리자 모드 · UAC·잠금 화면…"으로 바뀐다.
  - B systemprofile `diagnostic.ndjson`에 새 `admin-desktop` 실패 기록이 없다.
  - UAC 화면 캡처와 클릭 결과를 남긴다.
  - SYSTEM 하이브에 GPU 지정 값이 있다.

## 단계와 판정

1. 준비(화면 점유 없음)
   - preflight READY → prepare 설치 → B SSH로 GPU 지정 값 확인 → 터널링 서버 `/healthz` 확인.
2. B 지원 시작
   - SSH 작업 스케줄러로 B 사용자 세션에 `RemoteAssist.Update.exe`를 띄우고, 사용자가 UAC를 승인한다.
3. A 접속
   - PASS: 상태에 "관리자 모드"가 표시된다.
   - FAIL: "관리자 모드를 시작하지 못했다"가 표시되면 바로 중단하고 diagnostic HRESULT를 수집한다.
4. UAC 유발
   - SSH 작업 스케줄러로 B 사용자 세션에서 `Start-Process cmd -Verb RunAs`를 실행한다. 키 조합 전달 문제를 피하기 위해 이렇게 띄운다.
   - PASS: 10초 안에 어두운 UAC 동의 화면이 A 영상에 보인다.
5. A에서 UAC **예** 클릭
   - PASS: UAC가 닫히고 관리자 명령 프롬프트가 뜬다. 뜬 창은 SSH로 종료한다.
6. (선택) 상단 **Ctrl+Alt+Del** 버튼
   - PASS: 보안 화면이 A에 보이고, A에서 **취소**를 눌러 돌아온다.

## 결과 (2026-10-23 23:33~23:37 KST, 점유 약 4분)

- 준비 중 결함 2개를 찾아 고쳤다.
  - `e2e-prepare`: B 기본 셸이 cmd라 원격 명령의 따옴표가 깨졌다. `-EncodedCommand`로 바꿨다.
  - `install-host-dev`: 서비스를 새로 만들면 `ImagePath`에 따옴표가 빠졌다(unquoted service path). 이 때문에 `RemoteAssist.Update.exe`가 "Service does not belong…"으로 실패했다. 따옴표를 넣도록 고쳤다.
- 관리자 모드 PASS: "관리자 모드 · UAC·잠금 화면과 관리자 창도 조작할 수 있다." 표시. SYSTEM 진단 기록에 새 실패가 없다(시험 전후 19줄).
- 관리자 창 조작 PASS: A에서 B의 관리자 명령 프롬프트 X를 눌러 닫았다.
- UAC PASS: 보안 데스크톱 동의 화면("Windows 명령 처리기")이 A에 보였다. A에서 **예**를 누르자 관리자 명령 프롬프트가 떴다. 첫 시도는 B 쪽에서 4초 안에 승인돼 화면을 보지 못했고, 두 번째에 A에서 확인했다.
- Ctrl+Alt+Del PASS: 보안 화면이 A에 보였고, A에서 **취소**로 돌아왔다.
- 정리: B 제거(서비스·설치 폴더·허가·GPU 지정·방화벽 규칙 모두 없음 확인), 임시 폴더 삭제, A 터널링 서버 종료, TLS 키 삭제.

## 중단·정리

- 중단 조건: 상태 문구 FAIL, 10초 안에 UAC가 보이지 않음, 클릭 무반응. 이때는 B 사람이 UAC에서 **아니요** 또는 Esc를 누르고, 보안 화면이면 **취소**를 누른다.
- 점유 시간: 단계 3~6 약 3분.
- 정리: Viewer 탭 닫기 → B `install-host-dev.ps1 -Action Remove`(허가·GPU 지정 포함) → A 터널링 서버 종료 → TLS 키 삭제.
